# Corporate Carbon Disclosure Reconciliation Desk

**Iteration:** WS-004  
**Status:** APPROVED - source selection and validation-plan freeze; no proof result yet

This project is a bounded reviewer tool for deciding whether a company-level energy/emissions calculation can be reproduced from explicit activity, unit, factor-category, and factor-year evidence. Unsupported or incomplete disclosures must route to review rather than producing an inferred assurance result.

## Current boundary

Human approval covers one source-contract check, at most three permitted public SECR account documents, the official 2026 UK conversion-factor file, and a six-case local proof. No implementation result, production accuracy, compliance conclusion, audit assurance, hosting, or publication is claimed yet.
