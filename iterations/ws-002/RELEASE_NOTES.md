# Product Recall Match Desk v1.0.0

WS-002 demonstrates a bounded, explainable recall-to-catalog matching workflow for catalog operations review.

## Included

- Public no-login reviewer workbench backed by the real Python matcher.
- Deterministic match, no-match and review-needed queues with field-level reasons.
- Recorded openFDA provenance, reproducible fingerprints and JSON/CSV exports.
- A 20-row synthetic benchmark reproducing 20/20 independently declared labels.
- Twenty-one automated tests plus a hosted 13-test verification control.
- Three-page client-facing work sample PDF.

## Boundary

This fixture-backed portfolio project is not medical advice, a public alert, a current recall-status service, production accuracy evidence or a production catalog integration.

Public demo: https://product-recall-match-desk.vercel.app
