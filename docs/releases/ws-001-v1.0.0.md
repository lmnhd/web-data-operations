## Observed behavior

- Six update-tagged comparisons: zero differences in the six tracked fields, all ignored.
- One cancellation comparison: five field differences, routed to review for missing qualification data.
- One labeled synthetic example: changing the maximum value changes the decision while the input remains unchanged.
- Seventeen automated tests pass; source normalization, actual execution, rule changes, access boundaries and JSON/CSV exports are covered.

Each Run invokes the Python engine. The UI exposes before/after fields, reason codes, source metadata, exact-run downloads and actual code excerpts. The test button executes the tests locally.

## Scope and review

The user reviewed the working demo and PDF and explicitly approved publication. Implementation and browser verification were performed by the same agent, not an independent auditor. Pull request: https://github.com/lmnhd/web-data-operations/pull/1

This release publishes source, sanitized historical data, tests, recorded screenshots and the PDF. The interactive service is not publicly hosted yet. Two historical public records and a synthetic scenario do not establish source-wide coverage, current data availability, production scale or business impact. No scheduled collection, contact enrichment or paid hosting is included. Public source data: Find a Tender, Open Government Licence v3.0.
